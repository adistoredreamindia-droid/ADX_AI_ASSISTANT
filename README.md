# ADX AI Assistant

Personal Android assistant project inspired by the supplied reference screens.

## Included now
- ADX branding and dark blue UI
- Home dashboard
- Navigation drawer
- Memories / trained-task screen
- Chat screen
- Settings structure
- ADX Rules screen
- Android permissions scaffold for microphone/camera/contacts/calls/SMS/notifications
